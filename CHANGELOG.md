# Changelog

## 1.1 — October 2026
- Removed the "Due in the next 7 days" line from notes.

## 1.0 — October 2026
First numbered release.
- Per-student summary: current grade (matches the Gradebook Total, including unposted grades) and number of assignments not submitted. Missing includes any recorded 0.
- Note details: section and instructor, average on submitted work, missing work timing (last 14 days vs. earlier), category scores, last Canvas activity and last submission.
- Flagging by grade, missing work, and inactivity, with adjustable thresholds.
- Buttons: Copy note, Copy + TargetX (Faculty Alerts), Search TargetX, Adjunct Alert (pre-filled Faculty Early Alert Form), Copy all flagged notes, Download CSV.
